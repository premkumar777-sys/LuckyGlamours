# LuckyGlamours — Haute Beauté & Aesthetic Atelier

> A completely original, ultra-luxury digital brand experience for **LuckyGlamours** (*Haute Beauté & Aesthetic Atelier*). Built with Next.js 14, React 18, TypeScript, Tailwind CSS, and Framer Motion.

---

## Brand Direction & Identity

- **Brand**: LuckyGlamours (*Maison de Haute Beauté*)
- **Aesthetic**: High-fashion editorial, quiet luxury, museum-grade typography, warm tactile palette.
- **Palette**: Warm Ivory (`#FAF8F5`), Alabaster Cream (`#F4EFEA`), Deep Velvet Noir (`#0E0D0C`), Champagne Bronze (`#C5A880`), Subdued Gold (`#D4AF37`).
- **Typography**: Editorial High-Fashion Serif (*Cormorant Garamond* / *Playfair Display*) paired with geometric modern sans (*Plus Jakarta Sans*).

---

## Experience & Architecture

1. **Cinematic Opening Curtain**: Rapid, non-blocking brand reveal (<1.6s) with golden monogram insignia and smooth unmasking.
2. **Minimalist Morphing Navigation**: Clean logo header that transitions smoothly into a floating frosted glass capsule navbar with an editorial mobile menu.
3. **Cinematic Hero**: Full-viewport canvas with mouse tilt parallax depth, dramatic serif typography, and direct booking actions.
4. **Brand Philosophy**: *"BEAUTY IS NOT A TEMPLATE."* scroll-linked manifesto with dual-layer composition.
5. **Haute Services Collection**: Interactive runway collection browser (not a card grid!) with duration, pricing, protocol highlights, and an in-depth *"Explore Lookbook"* slide-over drawer.
6. **The Signature Experience**: 5-stage interactive beauty journey (*01 Consultation*, *02 Design*, *03 Transformation*, *04 Finish*, *05 Reveal*) with sensory atmosphere notes and timeline progress.
7. **Interactive Before / After Transformation**: Draggable split-screen comparison slider with touch gesture support, keyboard accessibility (`role="slider"`), and micro-annotations across 3 client cases.
8. **Asymmetrical Editorial Portfolio**: High-fashion magazine layout with staggered aspect ratios, category filtering, and project case study modals.
9. **Craftsmanship & Beauty Details**: Macro photography horizontal gallery focusing on lip architecture, cellular dewy skin, feathered brow precision, and artisanal Japanese brushes.
10. **The Artist Behind The Transformation**: Editorial profile of Elena Rostova with credentials, Parisian master training, and direct consultation CTA.
11. **Client Testimonials**: Large typographic quote carousel showcasing verified VIP and gala reviews.
12. **Multi-Step Concierge Booking**: 5-step interactive reservation experience (*Service → Date → Time → Guest Dossier → Confirmed Reservation Pass*) with refreshment selection, operating both in-page and as a modal from any CTA.
13. **Private Inquiries & Concierge**: Madison Avenue & Place Vendôme coordinates, atelier hours, direct lines, and confidential inquiry dispatch form.
14. **Architectural Footer**: Live New York & Paris atelier clocks, minimal navigation, return-to-top button, and closing statement: *"BEAUTY, WITH INTENTION."*

## Getting Started

### Prerequisites
- Node.js 18.17+ or 20+

### Installation & Local Run

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
